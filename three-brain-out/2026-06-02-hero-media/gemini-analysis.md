# Gemini (visual/brand lens) — HE hero media

**Verdict: Ship the animation.**

Strongest reason: for skeptical GovCons the "aha" is seeing the *engine* work, not the dashboard. A static image is a claim; an animation is a demonstration — it proves the "in minutes" promise and removes the cognitive load of imagining how the tool works.

Risks of the alternatives:
- **Static:** "vaporware / 2020 template" perception; fails to convey speed.
- **Video:** "enterprise heavyweight" / sales-pitch friction; autoplay looks blurry, play-button loses ~60% of viewers; implies complexity.

3 tweaks that matter more than format:
1. "Engine glow" — a scanning/data-crunch light sweep across the card before the 85% appears, to validate the *analysis*.
2. Tactile decision gates — STOP feels firm/muted; GO uses cyan with a soft glow, so it reads as a *defensible* choice.
3. Variable pacing — snappy irregular typing, smooth relentless pipeline; makes it feel alive.

Trust-killer: **slow motion.** If the full loop runs >8–10s it signals the tool is a bottleneck. Must be aggressive/fast.
